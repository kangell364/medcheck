# Documents worth downloading

Derived from the statutory citations printed in Pearson VUE #124401, not from
recollection. The Texas sections of that outline name the exact chapter and
section behind each sub-topic; this is that list, sorted by how much of the
exam each chapter carries and by how badly a draft needs it.

**Why any of this is needed.** `statutes.capitol.texas.gov`, `tdi.texas.gov`,
Justia and FindLaw are all blocked by the build environment's network proxy.
Web search works but returns second-hand summaries, which have already been
caught contradicting each other on this project. For the 100 general-knowledge
questions that is survivable — those are stable industry concepts. For the 30
Texas questions it is not: a lesson about a statute written without the
statute in front of the writer will read fluently and be occasionally wrong.

**Where.** <https://statutes.capitol.texas.gov> → Insurance Code → the chapter.
Each chapter downloads as HTML or PDF, free. If a whole-code download is
offered, one file beats forty.

## Tier 4 — workers' compensation

Cited from a different code entirely:

- **Texas Labor Code, Title 5** — chapters **401** (definitions), **406**
  (coverage and employer election), **408** (benefits).

> **Watch this one.** Chapter 401 exists in *both* codes and is cited from
> both. Insurance Code 401.051–.056 is examination of records; Labor Code
> 401.011 is workers' compensation definitions. They are unrelated. If a
> chapter number looks odd for its subject, check which code it came from.

§19.1301–.1320, §21.4, §21.111, §21.115, §21.201, §29.1.

## Do not download

- **Any competitor's study guide, question bank or flashcards.** Their
  expression is their copyright, and a prep business that has ingested a
  rival's material is a lawsuit with a website attached.
- **ISO policy forms.** Explaining what an HO-3 covers is general industry
  knowledge. Reproducing the form's wording is not ours to reproduce.
- **Recalled, leaked or "real" exam questions, from anywhere.** #124400
  describes exam-security monitoring and score cancellation. Material built on
  stolen questions risks the business and can void students' results — the one
  mistake here whose consequences are legal rather than technical.
